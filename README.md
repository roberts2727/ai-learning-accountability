The associated personal fundraiser supports practical AI learning, educational materials, software and cloud resources, while also helping reduce debt that competes with those goals:

**Campaign:** https://www.gofundme.com/f/help-roberto-advance-his-ai-learning-journey

## What this repository proves

- Learning claims are tied to inspectable artifacts.
- Experiments begin with defined questions, budgets, and success criteria.
- Progress reports disclose successes, failures, costs, and next actions.
- Learning expenses and debt reduction are reported separately.
- Claims are labeled **Verified**, **Documented**, or **Reported** based on evidence strength.

## Privacy and disclosure boundary

This repository will never contain:

- Passwords, API keys, tokens, or encrypted credential files.
- Bank, card, transfer, tax, or identity-verification data.
- Donor email addresses, phone numbers, or nonpublic identities.
- Raw private model transcripts or proprietary prompts.
- Employer, customer, or enterprise identifiers not already authorized for publication.
- Receipts containing sensitive information.

Only aggregate financial totals and sanitized technical evidence are published.

## How accountability works

1. Define an experiment and measurable success condition.
2. Approve a spending cap before using learning funds.
3. Produce an inspectable artifact.
4. Record the actual result, cost, failure modes, and next decision.
5. Reconcile funds and publish a monthly update.

Questions and constructive scrutiny are welcome. Repetitive promotion, automated spending requests, manipulation, and credential solicitation are not.
